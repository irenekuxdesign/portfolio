# Irene Kuo 作品集網站

## 檔案
- index.html：首頁
- better-direct.html、gcu.html、legal-spend.html：三個案例
- site.css、site.js：版面和動畫
- assets/：所有圖片和影片
- resume.pdf：請自行加入履歷（檔名必須是 resume.pdf）

## 上傳到 GitHub Pages
1. 建立名為「帳號.github.io」的 Public repository
2. 點「uploading an existing file」
3. 把這個資料夾裡的所有檔案和 assets 資料夾一起拖進去，按「Commit changes」
4. Settings → Pages → Source 選「Deploy from a branch」，Branch 選「main」，按 Save
5. 一兩分鐘後打開 https://帳號.github.io

## 之後修改
在 GitHub 上傳同名檔案覆蓋即可，網站會自動更新。
